# Landing Page — Nimbus

**OIBSIP · Web Development & Designing · Level 1 · Task 1**

A visually polished, fully responsive static landing page for a fictional
productivity product called **Nimbus**. Built to demonstrate foundational
HTML5 + CSS3 layout skills — no JavaScript is used.

## 🎯 Objective
Construct a clean, professional product landing page with a clear visual
hierarchy, consistent branding, and a layout that holds up from desktop down
to mobile widths.

## ✅ Feature Checklist (all met)
- [x] Sticky navigation bar with 3 navigation links (Features, About, Testimonials)
- [x] Hero section with headline, subheadline, and call-to-action buttons
- [x] Three distinct content sections — **Features**, **About**, **Testimonials**
- [x] Footer with placeholder contact / social links
- [x] Consistent colour palette (violet + amber) across every section
- [x] Responsive layout using **CSS Flexbox & Grid** — no breakage on mobile
- [x] No element overlap — intentional padding, margin & `box-sizing: border-box`
- [x] Clean typography with multiple font sizes (Sora for headings, Inter for body)

## 🛠 Tech Stack
- HTML5 (semantic structure)
- CSS3 (custom properties, Flexbox, Grid, `clamp()` fluid type, media queries)
- Google Fonts — Sora & Inter
