# Personal Portfolio

**OIBSIP · Web Development & Designing · Level 1 · Task 2**

A responsive personal portfolio website that acts as a digital résumé —
showing an intro, skills, projects, and a contact section. Built with
HTML5, CSS3, and a small amount of vanilla JavaScript for interactivity.

## 🎯 Objective
Create a portfolio site that presents who you are, what you can do, and how
to reach you — fully responsive on desktop and mobile.

## ✅ Feature Checklist (all met)
- [x] Profile / hero section — name, role title, and photo/avatar placeholder
- [x] About Me section (2–3 sentences)
- [x] Skills section — visual chip grid
- [x] Projects section — 3 project cards (title, description, GitHub link placeholder)
- [x] Contact section — name, email, and social icons + a demo contact form
- [x] Smooth-scroll navigation between sections
- [x] Consistent branding (colour scheme + font family throughout)
- [x] Fully responsive (desktop + mobile, with a working mobile menu)

## 🛠 Tech Stack
- HTML5 · CSS3 (Flexbox, Grid, custom properties, media queries)
- Vanilla JavaScript — mobile menu toggle, scroll-spy nav highlight, form validation
- Google Fonts — Space Grotesk & Inter
